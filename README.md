# チャーシューメン、チャーシュー12倍

GitHub Pagesで動くスマホ向けブラウザゲーム。初期は特製チャーシューメン（チャーシュー6枚）。

- タップで1枚、長押しで連続投下。投下位置は自動でラーメン上を周回します。
- 長押し中の上下スワイプで周回する円の大きさを調整します（奥行きも動きます）。
- 各チャーシューは2.5D座標（左右・奥行き・高さ）と速度を持ち、重力と相互衝突で動きます。
- 肉が器の外へ移動し、物理的に下へ落ちたらゲームオーバー。強制排出・時間経過によるゲームオーバーはありません。
- 最終枚数÷6を倍率として表示（9枚で1.5倍、12枚で2倍）。
- 1枚12g／厚さ7mm／70円、ラーメン950円。お釣りは1,000円単位に切り上げたお預かり額から計算し、リザルトのみ表示。
- 軽量な2D Canvas描画とスプライト・背景キャッシュ、近傍グリッドの衝突判定（総当たりを回避）。

本作は奥行き付き2.5D物理シミュレーションで、完全な3D剛体エンジンではありません。

GitHub Pages: https://ryg4mk.github.io/chashu-12x/

## v7: 着地後の固定と本当の積み重なり

- 初期チャーシュー6枚は土台として固定。
- 追加分は接地してから、**1.6秒以上経過し、約0.45秒間ほぼ静止**すると固定化されます。空中のチャーシューや器から落下中のものは固定しません。
- 固定済みチャーシューは他のチャーシューの衝突を受けても動かず、その上に新しいチャーシューが重なります。
- 新しいチャーシューはスープか他のチャーシューに支えられるまで重力で落下し、支えを失って器の外へ落ちるとゲームオーバーです。固定処理そのものを失敗判定には使いません。
- 山が高くなった部分には、山の上からチャーシューが落ちるよう投下開始高度を調整します。
