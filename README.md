# チャーシューメン、チャーシュー12倍

無料のスマホ／PC向けブラウザゲームです。HTML / CSS / JavaScript のみで動き、GitHub Pages に公開できます。

## 遊び方

- 特製チャーシューメンに最初から6枚のチャーシューが入っています。
- **タップ／クリック：** 1枚落とす。
- **長押し：** チャーシューを連続で落とす。
- **長押し中に指を左右へ動かす：** 落とす位置を調整する。指を動かさない場合は投下位置が自動で左右に移動します。
- 同じ場所に集中すると周囲のチャーシューが少しずつ押し出されるので、位置を考えて盛り付けてください。
- **器からチャーシューがこぼれたら終了。** こぼれた1枚が画面上に落下してからリザルトが表示されます。
- リザルトは6枚＝1倍で計算し「チャーシューメン、チャーシュー◯倍」と表示。重量・厚さ・会計・お預かり・お釣りもリザルトのみ表示します。
- お預かりは会計金額以上の1,000円単位に切り上げて計算します。

## 数値

特製チャーシューメン950円、チャーシュー1枚70円／12g／7mm、初期6枚。会計は「950円＋チャーシューの合計枚数×70円」のゲーム内特別会計方式です。

## 描画と負荷

- 背景と器はオフスクリーンCanvasへ事前描画して再利用。
- チャーシューの絵は8種類のスプライトに事前描画して再利用。
- 周囲との接触判定は着地時に実行し、毎フレームの全ペア衝突計算を廃止。
- 古いチャーシューはほぼ停止している間は座標更新を省略。
- ビルドツール・外部ライブラリ・画像ダウンロードは不要。
