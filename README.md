# チャーシューメン、チャーシュー12倍

GitHub Pages で遊べる無料ブラウザゲーム。斜め見下ろしのラーメンにチャーシューを落とし、12倍盛りを目指します。画像素材・外部ライブラリ・ビルド工程は不要です。

## 遊び方

- 最初からチャーシュー6枚が入った特製チャーシューメン。ここから追加して合計72枚（12倍）を目指す。
- スマホでは画面をタップ、PCではクリックまたはスペースキーでチャーシューを落とす。
- 3回はみ出したらゲームオーバー。72枚に到達するとクリア。
- 枚数、厚さ、重量、お会計、6,000円からのお釣りを表示。最高記録はブラウザに保存。

## 会計ルール

- 特製チャーシューメン: 950円
- チャーシュー: 1枚 70円（6枚 420円） / 厚さ7mm / 重さ12g
- **ゲーム内価格 = 950円 + 合計チャーシュー枚数 × 70円**
- 初期6枚はラーメンに入った状態でスコア・チャーシュー代にも算入。
- 72枚時 = 950円 + 72×70円 = **5,990円**。6,000円支払いで**お釣り10円**。
- 注: 特製チャーシューメン950円の価格とは別に、初期6枚を含む全チャーシューの代金を加算する**ゲーム内特別会計方式**です。
