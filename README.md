# チャーシューメン、チャーシュー12倍

GitHub Pages で公開できる、HTML/CSS/JavaScript だけで作った無料ブラウザゲームです。

## ゲーム概要

斜め見下ろしの 3D 風ラーメンの上に、チャーシューをどんどん落として積み上げます。

- 最初から **6枚** 入った **特製チャーシューメン**
- タップ / クリック / スペースキーで **チャーシューを連続追加**
- チャーシューは **物理演算風** に落下・衝突・押し合いをする
- **クリアなしの無限プレイ**
- **器からチャーシューが落ちたらゲームオーバー**

## 表示される情報

- 今の枚数
- 最高記録
- お会計
- お釣り（リザルトのみ、会計に応じて千円単位でお預かり額を切り上げ）
- チャーシュー重量（リザルトのみ）
- チャーシューの厚み（リザルトのみ）

## 設定値

- 特製チャーシューメン: **950円**
- 初期チャーシュー量: **6枚**
- チャーシュー 1枚: **12g / 7mm / 70円**
- チャーシュー 6枚: **420円**
- お会計計算: **950円 + (合計枚数 × 70円)**

## 背景演出

後ろの壁に、木の札の縦書きメニューを表示しています。

- 餃子

- 野菜炒め
- ラーメン
- 特製チャーシューメン

## ファイル

- `index.html` : 画面構成
- `style.css` : レイアウト / スマホ対応
- `game.js` : 描画 / ゲームループ / 物理挙動

## 公開方法

1. `index.html`, `style.css`, `game.js` をリポジトリ直下に配置
2. GitHub の **Settings → Pages** で **Deploy from a branch** を選択
3. `main` / `/(root)` を選んで保存

公開URL例:

- `https://ryg4mk.github.io/chashu-12x/`

## 表示・読み込みの安定化

GitHub Pages のキャッシュで HTML / CSS / JS の世代が食い違わないよう、`index.html` 単体で動作する構成です。`style.css` / `game.js` は編集用の複製です（公開する場合は index.html にも反映してください）。
