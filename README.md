# チャーシューメン、チャーシュー12倍

GitHub Pages 向けのスマホ対応ブラウザゲーム。

- タップ：チャーシューを1枚落とす
- 長押し：一定間隔で連続投下（長押しを離すと停止）
- 初期：特製チャーシューメン、チャーシュー6枚
- 器からチャーシューが落ちると終了。クリア条件なし
- リザルト：「チャーシューメン、チャーシュー◯倍」（枚数÷6、最大小数2桁）
- プレイ中は枚数、最高記録、会計のみを表示
- リザルトのみ重量（1枚12g）、厚み（1枚7mm）、支払い・お釣りを表示
- 会計は950円＋合計チャーシュー枚数×70円。支払いは千円単位に切り上げ

背景は木の縦書き札5枚（餃子、ライス、野菜炒め、ラーメン、特製チャーシューメン）。ラーメンとチャーシューを立体感のあるCanvasイラストで描画し、簡易剛体物理を使用。

GitHub Pages公開用は `index.html` だけで完結します。 `style.css` と `game.js` は編集用の複製です。
