# チャーシューメン、チャーシュー12倍

GitHub Pages で動く、スマートフォン・PC対応の無料ブラウザゲームです。

## 遊び方

- タップするとチャーシューを1枚投下します。
- 長押しすると左右に動く投下位置から連続投下します。
- 投下位置は器の中央を通って左右に一定速度で往復し、両端だけ少し器からはみ出します。
- チャーシューが器の外へ落ちたらゲームオーバー。クリア上限はありません。
- スコアは初期6枚を基準に倍率表示（9枚=1.5倍、12枚=2倍）。

## 積み重ね処理（v8）

- 初期の6枚は土台として固定。
- **追加された直近10枚は固定せず、従来どおり重力と衝突で動きます。**
- 投下順が直近10枚より古くなったチャーシューは、**十分な重なりで安定して支えられ、静止が続いた場合だけ固定**します。
- 支えのない空中のチャーシュー、斜めに引っかかっただけのチャーシューは固定しません。
- 新たなチャーシューの投下開始高さは、**着地・固定済みのチャーシューだけ**を参照。落下中のものを基準にして空中に連なって出現する不具合を修正しました。
- 器の外へ出たチャーシューは、物理座標で落下したときだけゲームオーバーになります。
- 軽量な **2.5D**（左右・奥行き・高さ）物理モデルです。完全な3D剛体演算ではありません。

## 会計ルール

- **特製チャーシューメン950円にはチャーシュー6枚を含みます。** 7枚目から1枚70円追加。
- お会計 = 950円 + max(0, 合計枚数 - 6枚) × 70円。初期6枚は950円、7枚で1,020円、12枚で1,370円。
- 1枚12g / 厚さ7mm。
- 終了時には枚数・倍率・重量・厚み・会計・お預かり・お釣りを表示します。
- お預かり額は1,000円単位に切り上げて計算します。

## 最新の操作仕様
- 横一直線の着地点ガイドに沿って、中央も含めて均等に狙える左右往復式。
- 進行方向は左右端で折り返す。投下範囲は左右とも器の縁を少し越える。
- 危険な位置を赤色で知らせる表示はなし。
- タップで1枚、長押しで連続投下。直近10枚の物理処理と倍率リザルトは維持。

## 結果の共有

リザルト画面に「共有」ボタンがあります。対応端末では画像ファイル・「チャーシュー麺、チャーシュー◯倍！？」という結果文・ゲームURLを、端末の共有メニューからアプリへ送れます。画像は実際に積み上げたラーメンのゲーム画面を元にしたPNGです。

画像付きの端末共有に対応していないブラウザでは、ボタンを押すと結果画像を保存し、投稿文とゲームURLをコピーできるようにします。保存画像は共有先で手動添付してください。特定のSNSへ強制的に移動しません。
