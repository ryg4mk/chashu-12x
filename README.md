# チャーシューメン、チャーシュー12倍

GitHub Pages で動く、スマートフォン・PC対応の無料ブラウザゲームです。

## 遊び方

- タップするとチャーシューを1枚投下します。
- 長押しすると自動で楕円を描きながら連続投下します。
- 投下位置は一定速度で楕円形に周回し、左右の端付近だけ少し器からはみ出します。
- チャーシューが器の外へ落ちたらゲームオーバー。クリア上限はありません。
- スコアは初期6枚を基準に倍率表示（9枚=1.5倍、12枚=2倍）。

## 積み重ね処理（v8）

- 初期の6枚は土台として固定。
- **追加された直近10枚は固定せず、従来どおり重力と衝突で動きます。**
- 投下順が直近10枚より古くなったチャーシューは、**十分な重なりで安定して支えられ、静止が続いた場合だけ固定**します。
- 支えのない空中のチャーシュー、斜めに引っかかっただけのチャーシューは固定しません。
- 新たなチャーシューの投下開始高さは、**着地・固定済みのチャーシューだけ**を参照。落下中のものを基準にして空中に連なって出現する不具合を修正しました。
- 器の外へ出たチャーシューは、物理座標で落下したときだけゲームオーバーになります。
- 軽量な **2.5D**（左右・奥行き・高さ）物理モデルです。完全な3D剛体演算ではありません。

## 会計ルール

- ラーメン950円 + チャーシュー枚数 × 70円。
- 1枚12g / 厚さ7mm。
- 終了時には枚数・倍率・重量・厚み・会計・お預かり・お釣りを表示します。
- お預かり額は1,000円単位に切り上げて計算します。

## v9: 狙って落とす難易度調整

- 楕円軌道の大部分は器の内側で、左右の端付近だけ少しはみ出す。
- 投下位置の輪は常に同じ色で表示し、危険な位置は色で知らせません。
- 長押し中も外側へ落ちるため、タイミングよく指を離す必要がある。
- 波打つような軌道変化を撤廃し、固定された楕円を一定速度で回転。
- 外に落ちたものは既存の重力・落下判定でゲームオーバー。

## v10 テンポ調整
- 周回を従来の約1.7倍速から開始し、枚数に応じて緩やかに速度が上がる。
- 長押しの2枚目からの投下間隔を約235msへ短縮し、タップ連打の反応も改善。
- 重力を強くして着地待ちを短縮。着地時と投下時には短いリング状の反応を表示。
- 器の外へ本当に落ちた場合のみゲームオーバー、直近10枚の可動と固定条件は維持。

## v11 楕円軌道
- 不規則な半径変化をなくし、一定速度の楕円周回に変更。
- 左右の両端付近のみ器から少しはみ出す（標準軌道のおよそ20%）。
- ゲーム内の見た目と落下判定の位置合わせを改善。

## v12 表示調整
- 着地点・周回軌道・投下時のエフェクトから赤色の危険表示を撤廃。落下判定自体は維持。
- リザルトの倍率表記は「チャーシュー1.5倍！？」のように表示。
