# チャーシューメン、チャーシュー12倍

斜め見下ろし型のラーメンに、左右に動くチャーシューをタイミングよく落として何枚積めるか競うブラウザゲームです。

- スマートフォン：ゲーム画面をタップして落下
- PC：クリックまたはスペースキーで落下
- 3回はみ出すとゲームオーバー
- 12枚以上もチャレンジ可能
- ベスト記録はブラウザ内に保存

ゲーム本体は `index.html` だけで動作します。外部ライブラリ不要です。

## プレイ
https://ryg4mk.github.io/chashu-12x/

## 公開手順
GitHub の Settings → Pages から Deploy from a branch → main / (root) を選択してください。
